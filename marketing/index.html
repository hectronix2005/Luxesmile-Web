Qué falta en esta página, y por qué

Esta página muestra solo lo que el navegador puede consultar por sí mismo. Dos análisis que sí estamos haciendo no están aquí, y conviene saber el motivo en vez de encontrarse una pestaña vacía.

Análisis de campañas (Google Ads)

La API de Google Ads necesita un developer token y no admite llamadas desde el navegador. Meterlo en esta página sería publicarlo: el repositorio del sitio es público. Hoy el análisis de campañas se hace fuera y se entrega como informe.

Análisis de conversaciones (WhatsApp / CRM)

Comprobado el 09-09-2026: la API de ZEUS no envía cabecera Access-Control-Allow-Origin, así que el navegador bloquea la consulta aunque haya credencial. Y aunque la enviara, no se puede poner un token de lectura del CRM en una página servida desde un repositorio público.

La salida, cuando se decida

Generar un archivo de agregados fuera y cargarlo aquí desde el disco, sin commitearlo. Queda pendiente de decisión: mientras tanto, ninguna cifra de campañas o conversaciones se guarda en este repositorio.
